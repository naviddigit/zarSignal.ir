# اپ موبایل زرسیگنال — اجرای دمو

## روی لپ‌تاپ ویندوز (بدون مک و بدون گوشی اندروید) — شدنی است

بهترین راه الان: **Expo Web** در مرورگر کروم.

```powershell
cd c:\Users\SMP\Desktop\ZarSignal.ir\source
npm run dev
```

ترمینال دوم:

```powershell
cd c:\Users\SMP\Desktop\ZarSignal.ir\source\apps\mobile
Copy-Item .env.example .env
# اگر وب روی همین سیستم است:
# EXPO_PUBLIC_API_URL=http://localhost:3000
npm install
npm run web
```

مرورگر معمولاً روی `http://localhost:8081` باز می‌شود. خانه کارت‌محور، منوی پایین مثل سایت (خانه / قیمت‌ها / ماشین حساب / تحلیل / بیشتر)، و صفحات قیمت و حساب را همان‌جا می‌بینی.

قیمت زنده نیاز به سرور وب دارد؛ اگر API بالا نباشد، صفحه هیرو همچنان کار می‌کند و تابلوی قیمت خطا می‌دهد.

## دو نسخه iOS و Android یعنی چه؟

| نسخه | روی ویندوز شما | چه لازم است |
| --- | --- | --- |
| **وب‌دمو (همین الان)** | بله — مرورگر | فقط Node |
| **اندروید واقعی** | با Android Studio امولاتور، یا گوشی اندروید + Expo Go | نصب Android Studio یا یک گوشی |
| **آیفون واقعی** | خودتان شبیه‌ساز ندارید | Expo Go روی آیفون دوستان/همکار، یا مک برای Simulator |

**بدون مک نمی‌توانید شبیه‌ساز آیفون بسازید.** ولی:
1. دمو را خودتان در مرورگر ویندوز ببینید (`npm run web`).
2. برای حس لمسی آیفون/اندروید، به کسی که گوشی دارد بگویید Expo Go نصب کند و QR کد `npm start` شما را اسکن کند (همان شبکه Wi‑Fi یا tunnel).

## دستور مشترک هر دو پلتفرم (Expo Go)

```powershell
cd apps\mobile
npm start
```

- آیفون: اپ **Expo Go** از App Store (رایگان برای تست)
- اندروید: اپ **Expo Go** از Play Store

نیازی به پابلیش فروشگاهی برای دمو داخلی نیست.

## پابلیش فروشگاهی

- اندروید Play و گیفت: فازهای بعدی پلن
- آیفون App Store: عمداً عقب است تا هزینه Developer نپردازید؛ تا آن زمان فقط Expo Go / وب‌دمو
