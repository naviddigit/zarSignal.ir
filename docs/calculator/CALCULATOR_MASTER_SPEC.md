# CALCULATOR_MASTER_SPEC

وضعیت: PDF مرجع در ۸ صفحه بررسی شد. فقط محاسبات صریح، پایدار و قابل آزمون اجازهٔ انتشار دارند.

## وضعیت ماژول‌ها

| ماژول | وضعیت |
| --- | --- |
| تبدیل واحد وزن | پیاده‌سازی‌شده: گرم، مثقال، سیر، کیلوگرم، اونس تروا، تولا، پنی‌ویت و گرین |
| تبدیل عیار | پیاده‌سازی‌شده برای عیارهای صریح سند |
| مظنه ۷۰۵ به گرم ۱۸ عیار | پیاده‌سازی‌شده در سرور؛ عبارت فرمول در رابط و باندل مرورگر منتشر نمی‌شود |
| طلا و آب‌شده پیشرفته | نیازمند تأیید ورودی، واحد و نسخهٔ فرمول |
| سکه و حباب سکه | SPEC_BLOCKER؛ بدون فرمول قطعی منتشر نمی‌شود |
| نقره | SPEC_BLOCKER؛ تا تعریف قطعی واحد و فرمول |
| طلای زینتی، اجرت و مالیات | SPEC_BLOCKER؛ وابسته به قانون جاری و مشخصات محصول |
| سود و زیان و حسابداری | SPEC_BLOCKER؛ نیازمند مدل حسابداری و Audit Trail تأییدشده |
| پیشنهاد خرید/فروش و رنگ تصمیم | ممنوع؛ ابزار محاسباتی توصیهٔ معامله تولید نمی‌کند |

## قواعد محصول

- حداکثر سه مرحله تا نتیجه: انتخاب محاسبه، ورود عدد، مشاهدهٔ نتیجه.
- ورودی قیمت می‌تواند دستی باشد یا با دکمه از آخرین دادهٔ معتبر بازار بارگذاری شود.
- فرمول‌های اختصاصی فقط سمت سرور اجرا می‌شوند؛ پاسخ عمومی فقط خروجی و نسخه را برمی‌گرداند.
- خروجی مشتق‌شده باید از قیمت مستقیم بازار تفکیک و برچسب‌گذاری شود.
- فرمول، مالیات، عیار یا آستانهٔ معاملاتی مبهم از روی نمونه‌ها حدس زده نمی‌شود.
