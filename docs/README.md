# مستندات زر‌سیگنال

منبع حقیقت اجرایی پروژه این پوشه است، نه چت‌های ChatGPT یا Codex.

## نقش‌ها

- مجتبی: منطق مالی و ایده محصول
- نوید: تصمیم نهایی
- ChatGPT Product: نوشتن و بازبینی Spec
- Cursor / Codex: فقط پیاده‌سازی Spec تأییدشده

## قانون

هیچ فرمول مالی، آستانه، یا قانون معامله از روی UI، LiveCloud یا کد قدیمی حدس زده نمی‌شود.

LiveCloud (`https://quizfi.ir/livecloud/`) فقط نمونه است؛ منبع فرمول نیست.
