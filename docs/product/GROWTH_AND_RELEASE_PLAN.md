# برنامه رشد و عرضه زرسیگنال

## جایگاه محصول

زرسیگنال باید پاسخ سه سؤال را سریع و قابل استناد بدهد: «قیمت چیست؟»، «این داده چه زمانی و از کجا آمده؟» و «با ورودی و ریسک خودم چه نتیجه‌ای می‌گیرم؟». ارزش ماندگار محصول از اعتماد، سابقه داده، ابزارهای شخصی و هشدارها می‌آید؛ شلوغ‌کردن صفحه با قابلیت‌های متعدد معیار رشد نیست.

## مدل درآمد

1. **رایگان:** قیمت، منبع، تازگی داده، صفحات بازار و ماشین‌حساب پایه برای جذب و اعتماد.
2. **خانگی:** فهرست شخصی، هشدار، مدیریت سرمایه، گزارش ساده و همگام‌سازی وب و موبایل.
3. **حرفه‌ای:** هشدارهای بیشتر، تاریخچه، گزارش پیشرفته، حسابداری تأییدشده و خروجی فایل.
4. **API:** کلید، سهمیه، گزارش مصرف، SLA و قیمت‌گذاری جداگانه برای توسعه‌دهندگان و کسب‌وکارها.
5. **B2B:** ویجت قیمت، پنل سفیدبرچسب و نمایشگر بازار برای طلافروشی و صرافی.
6. **Marketplace:** فقط پس از تثبیت هسته محصول؛ سهم از فروش ابزار و محتوای تأییدشده.

## مسیر رسیدن به ۱۰۰ هزار خریدار

هدف ۱۰۰ هزار خریدار به محصولی با مقیاس ملی نیاز دارد. مسیر قابل سنجش:

| مرحله | کاربر فعال ماهانه | خریدار فعال | معیار عبور |
|---|---:|---:|---|
| اثبات نیاز | ۵٬۰۰۰ | ۲۰۰ | بازگشت هفتگی بالاتر از ۳۰٪ و خطای داده کمتر از ۰٫۱٪ |
| تناسب محصول و بازار | ۵۰٬۰۰۰ | ۳٬۰۰۰ | تبدیل دوره آزمایشی به پرداخت بالاتر از ۸٪ |
| رشد سراسری | ۲۵۰٬۰۰۰ | ۱۵٬۰۰۰ | بازگشت ماه دوم بالاتر از ۴۵٪ و پشتیبانی پایدار |
| مقیاس ملی | ۱٬۵۰۰٬۰۰۰ | ۱۰۰٬۰۰۰ | کانال جذب سودآور و تمدید سالانه قابل پیش‌بینی |

این اعداد هدف عملیاتی هستند و تضمین فروش نیستند. هر مرحله فقط پس از رسیدن به کیفیت و نگهداشت مرحله قبل شروع می‌شود.

## حلقه استفاده ساده

1. کاربر از جست‌وجو یا لینک وارد صفحه یک بازار می‌شود.
2. قیمت، منبع و «چند ثانیه پیش» را بدون ثبت‌نام می‌بیند.
3. با ماشین‌حساب یا ابزار ریسک یک کار واقعی انجام می‌دهد.
4. برای ذخیره بازار یا هشدار، با موبایل وارد می‌شود.
5. اولین هشدار مفید و گزارش هفتگی او را برمی‌گرداند.
6. محدودیت تعداد هشدار، تاریخچه یا گزارش حرفه‌ای دلیل روشن خرید می‌شود.

## برنامه SEO و معرفی در پاسخ‌های هوش مصنوعی

- هر دارایی یک URL پایدار، متن منحصربه‌فرد، واحد، منبع، زمان، FAQ مرتبط، لینک داخلی و structured data هماهنگ با محتوای قابل مشاهده دارد.
- صفحات آموزشی بر اساس سؤال واقعی کاربر ساخته می‌شوند: تفاوت خرید و فروش، معنی واحد، تازگی داده، مدیریت ریسک و خطاهای رایج.
- محتوای انبوه و تکراری تولید نمی‌شود. هر صفحه باید داده یا پاسخ اختصاصی داشته باشد.
- Search Console، Bing Webmaster و گزارش crawl پس از استقرار فعال می‌شوند.
- `OAI-SearchBot` و موتورهای جست‌وجو در robots مسدود نمی‌شوند؛ بخش مدیریت و API خصوصی مسدود می‌مانند.
- هدف فنی Core Web Vitals: `LCP < 2.5s`، `INP < 200ms` و `CLS < 0.1` روی داده واقعی کاربران.

منابع مرجع: [Google AI search guidance](https://developers.google.com/search/docs/appearance/ai-features)، [Google Core Web Vitals](https://developers.google.com/search/docs/appearance/core-web-vitals)، [OpenAI publisher guidance](https://help.openai.com/en/articles/12627856).

## فازهای بعدی محصول

### P0 — لازم برای اولین فروش

- PostgreSQL مدیریت‌شده، migration، backup و مانیتورینگ
- منبع داده قراردادی یا مجوز روشن بازنشر؛ fallback و هشدار تأخیر
- ورود موبایل با ارائه‌دهنده OTP واقعی و تکمیل Google OAuth
- درگاه پرداخت، تأیید سمت سرور، تمدید، لغو و رسید
- تاریخچه قیمت و نمودار بدون داده ساختگی
- ثبت رخداد محصول: مشاهده قیمت، استفاده ابزار، ثبت‌نام، ساخت هشدار و خرید

### P1 — نگهداشت و تبدیل

- Watchlist ابری و هشدار Push/SMS
- داشبورد شخصی با خلاصه قابل توضیح
- فرمول‌های ماشین‌حساب، حسابداری و تحلیل فقط پس از رفع `SPEC_BLOCKER`
- گزارش هفتگی و یادآوری با کنترل کامل کاربر
- آزمایش دوره رایگان و paywall بر اساس ارزش مصرف‌شده

### P2 — Android و iOS

- تکمیل اپ Expo با همان قرارداد API و design tokens
- ورود موبایل، watchlist، Push، deep link و همگام‌سازی
- حالت خواندن آفلاین همراه زمان آخرین داده
- تست دستگاه واقعی، Crash reporting، Analytics و فرآیند انتشار فروشگاه‌ها

### P3 — API و B2B

- پورتال کلید API، سهمیه و نمودار مصرف
- webhook، status page و قرارداد SLA
- ویجت قابل جاسازی و پنل سفیدبرچسب

## داشبورد مدیریتی رشد

مدیریت باید این شاخص‌ها را روزانه نشان دهد: موفقیت و تأخیر دریافت داده، کاربران فعال، نرخ تکمیل ورود، ساخت اولین Watchlist، ساخت هشدار، شروع پرداخت، پرداخت موفق، تمدید، لغو، درآمد ماهانه، هزینه جذب و درخواست‌های پشتیبانی. هیچ Dark Pattern یا ادعای سود برای افزایش تبدیل استفاده نمی‌شود.
