# پلن اپ موبایل زرسیگنال — نسخه قوی (Astra + رشد)

تاریخ ثبت: ۲۰۲۶-۰۹-۲۸

## مأموریت

اپ زرسیگنال فقط تخته قیمت نیست. ارزش در اولین صفحه روشن می‌شود: **حباب، شفافیت زمان داده، دلیل و ریسک** — سپس پایش و اطلاع‌رسانی با اشتراک. هدف داخلی رشد تا ۵۰ هزار خریدار است و در UI به‌عنوان آمار واقعی یا تضمین نوشته نمی‌شود.

مراجع: `docs/ZarSignal_Astra_Homepage_Brief_FA.md`، `docs/product/GROWTH_50000.md`.

## قلاب زبان محصول

- **حباب:** فاصله قیمت با ارزش محاسباتی؛ شاهد است نه فرمان خرید.
- **شفافیت:** زمان دریافت، واحد، محدودیت؛ داده قدیمی پنهان نمی‌شود.
- **موقعیت:** خلاصه قابل‌فهم؛ تا آماده‌نبودن V5.4 بدون وعده «الان بخر».
- **بدون تضمین سود:** نزدیک ارتقا؛ جای H1 را نمی‌گیرد.

هیرو موقت: «از قیمت تا تحلیل موقعیت» / CTA «تحلیل مویرگی».

قیف: هیرو حباب → نتیجه پایه → نمونه کامل → ذخیره/هشدار → ثبت‌نام → trial ادمین → paywall → اعلان → بازگشت.
