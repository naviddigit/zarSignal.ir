# اولویت محصول (قفل‌شده با نوید)

## ارزش اصلی برای کاربر

1. قیمت زنده نمادها (بدون افشای منبع بالادستی در سایت/API عمومی)
2. حباب قیمت روی چارت + تاریخچه همان لحظه (اشتراک‌فروش)
3. API همان نمادها
4. زبان ساده برای اصطلاحات بازار (فردایی، مظنه، …)

## ممنوع

- نام یا لینک تأمین‌کننده بالادستی در UI/API عمومی
- حدس فرمول حباب از LiveCloud یا اعداد

## ارزش صفحه اول (تأییدشده)

1. قیمت طلا، نقره و ارز را فقط نبین؛ فاصله‌شان با ارزش محاسباتی را هم ببین.
2. زرسیگنال نشان می‌دهد این اختلاف از کجا آمده و داده‌ها چقدر تازه و قابل اتکا هستند.
3. تحلیل، ماشین‌حساب و مدیریت ریسک در یک مسیر واحد کمک می‌کنند آگاهانه‌تر تصمیم بگیری؛ سود را تضمین نمی‌کنند.
