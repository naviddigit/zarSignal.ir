# اولویت محصول (قفل‌شده با نوید)

## ارزش اصلی برای کاربر

1. قیمت زنده نمادها (بدون افشای منبع بالادستی در سایت/API عمومی)
2. حباب قیمت روی چارت + تاریخچه همان لحظه (اشتراک‌فروش)
3. API همان نمادها
4. زبان ساده برای اصطلاحات بازار (فردایی، مظنه، …)

## ممنوع

- نام یا لینک تأمین‌کننده بالادستی در UI/API عمومی
- حدس فرمول حباب از LiveCloud یا اعداد

## ترتیب ساخت

1. `MARKET_MODE=live` + دریافت دوره‌ای قیمت
2. مخفی‌سازی منبع بالادستی در خروجی عمومی (انجام‌شده در کد)
3. Spec فرمول حباب از مجتبی/ChatGPT → موتور + ذخیره سری زمانی حباب
4. چارت قیمت + لایه حباب روی همان تاریخچه
5. صفحه ورود کاربر اول: «چه می‌دهیم» خیلی ساده
6. API پولی روی همان داده

## از ChatGPT چه می‌خواهیم

پیام آماده در انتهای گفتگوی Cursor برای کپی به ChatGPT Product.
