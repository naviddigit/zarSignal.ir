# اولویت محصول (قفل‌شده با نوید)

## ارزش اصلی برای کاربر

1. قیمت زنده نمادها (بدون افشای منبع بالادستی در سایت/API عمومی)
2. حباب قیمت روی چارت + تاریخچه همان لحظه (اشتراک‌فروش)
3. API همان نمادها
4. زبان ساده برای اصطلاحات بازار (فردایی، مظنه، …)

## ممنوع

- نام یا لینک تأمین‌کننده بالادستی در UI/API عمومی
- حدس فرمول حباب از LiveCloud یا اعداد
- ادغام هوم‌گلد / ربات معامله / اسپرد / بستانکار داخل محصول عمومی زر‌سیگنال
- بازهٔ خنثی موقت (±۰٫۵٪ و مشابه) تا تأیید مجتبی — فقط عدد حباب و علامت ‎+‎/−‎

## Paywall (تأیید ChatGPT)

- **Free:** قیمت پایه، حباب/USD Gap لحظه‌ای، ماشین‌حساب پایه، چارت محدود ≈۲۴س، آموزش
- **Home:** تاریخچه کامل‌تر، چارت Price+Bubble، واچ‌لیست، هشدار محدود، مقایسه بازه، ابزار سرمایه
- **Professional:** تاریخچه بلند، هشدار/واچ‌لیست بیشتر، export، جزئیات methodology، API allowance محدود
- **API:** تعرفه مستقل — داخل Pro نامحدود نشود
- قیمت زنده پایه را کامل پشت paywall نگذار

اولویت paywall: History → Alerts → Watchlist → Advanced calc → Export → API
