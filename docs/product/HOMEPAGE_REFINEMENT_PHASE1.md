- Brief کامل `docs/ZarSignal_Astra_Homepage_Brief_FA.md` و ممیزی قبلی خوانده شد. تغییر اخیر، Hero مداری را با کارت آموزشی مستطیلی جایگزین کرده بود. بازگرداندن کل commit، اصلاحات درست حالت داده و دسترس‌پذیری را نیز از بین می‌برد؛ فقط ترکیب بصری اصلاح شد.

- API عمومی در این اجرا `status=ok` و ۹ quote داشت؛ زمان اولین مشاهده `2026-09-26T17:40:15.391Z`. این مشاهده، اتصال عمومی داده را ثابت می‌کند؛ جای ممیزی مستقیم DB نیست. نام منبع عمومی زرسیگنال است.
- `FORMULA_REGISTRY.md` و اجرای `live-bubbles.ts` همسو هستند: GOLD_BUBBLE و USD_GAP از تبدیل تأییدشده مظنه به ۱۸ عیار استفاده می‌کنند. Silver در runtime مسدود است. تست ریاضی نقره مجوز فعال‌سازی عمومی نیست.
- فایل Master Prompt V5.3 و Amendment Registry در docs پیدا نشد. هیچ Decision Engine، آستانه خنثی یا فرمول ارزی جدید از متن بازاریابی استنباط نشد.
- دادهٔ دلار با دلار ضمنی طلا مقایسه می‌شود، نه ارزش بنیادی دلار یا مدل درهم. پیشنهادهای ناسازگار Brief نباید نام مدل فعلی را عوض کنند.
- `/calculator` و کنترل‌های موجود خارج از تغییر هستند. وضعیت پوشش M01–M11 در این اجرا بازسنجی نشده و ادعای تکمیل نمی‌شود.

## اعتبارسنجی

- ۵۹ تست واحد از جمله Golden Tests و حالت داده پاس شدند.
- TypeScript بدون خطا.
- `npm run build` موفق؛ migration در build اضافه نشده است.
- Playwright: پنج viewport دقیق 360×800، 390×844، 430×932، 768×1024، 1440×1000 در light/dark؛ CTA بالای fold، بدون overflow و خطای مرورگر.
- بررسی حفظ انتخاب حرفه‌ای، نقرهٔ blocked، ناوبری، Escape، بزرگ‌نمایی متن و reduced motion.
- توقف دستی و توقف خارج viewport نیز تست شد. WebKit با اندازه 390×844: بدون خطای JavaScript و overflow، CTA در y≈304 با ارتفاع≈49px. این تست معادل دستگاه فیزیکی آیفون نیست.
- تصاویر و اندازه‌گیری‌ها: `artifacts/homepage-refinement/`. تصاویر محلی با MARKET_MODE=demo هستند؛ تأیید دریافت زندهٔ production جدا انجام شد.

## مرز انتشار و مرحله بعد

طبق Brief، خروجی فقط برای بازبینی است؛ push/deploy انجام نمی‌شود و rollback پروداکشن حفظ می‌شود. ابتدا طراحی تأیید شود. Phase 2 پیشنهادی: تأیید سند موتور تصمیم و adapter قیف، سپس اتصال گزارش‌های معتبر و آزمون فهم کاربر؛ نه افزودن وعدهٔ امکانات آماده‌نشده. هیچ تضمینی برای دستیابی به ۵۰ هزار خریدار از تغییر Hero قابل ارائه نیست.
