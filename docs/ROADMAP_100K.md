# نقشهٔ رشد زرسیگنال تا ۱۰۰ هزار کاربر

این سند ترتیب اجرا را مشخص می‌کند. هدف عددی به‌تنهایی معیار موفقیت نیست؛ اعتماد به داده، بازگشت کاربر و تبدیل به پرداخت معیارهای اصلی‌اند.

## فاز ۱ — اعتماد و زیرساخت

- اتصال قرارداددار به حداقل یک API بازار و یک منبع پشتیبان
- ثبت source، business timestamp، fetched timestamp، واحد و وضعیت تازگی برای هر نرخ
- PostgreSQL production، migration، backup و مانیتورینگ
- ورود موبایل OTP با rate limit و ورود Google
- داشبورد کاربر و ثبت رضایت آگاهانهٔ ریسک
- صفحات روش‌شناسی، وضعیت سرویس، حریم خصوصی و شرایط استفاده

معیار خروج: هیچ قیمت بدون منبع و زمان منتشر نشود؛ خطای feed ظرف چند دقیقه دیده شود.

## فاز ۲ — محصول قابل پرداخت

- ابزار مدیریت سرمایه برای کاربر خانگی و حرفه‌ای
- مرکز ماشین‌حساب ماژولار پس از رفع SPEC_BLOCKERهای واحد، عیار، مالیات و گردکردن
- حسابداری آبشده با تراکنش برگشتی و audit log
- پلن‌ها، درگاه پرداخت، تمدید و لغو اشتراک
- API key، سهمیه، metering و مستندات نسخه‌بندی‌شده

معیار خروج: فعال‌سازی اشتراک و دسترسی API کاملاً سمت سرور و قابل حسابرسی باشد.

## فاز ۳ — جذب و ماندگاری

- صفحات شاخص‌پذیر برای هر دارایی، واژه‌نامه و آموزش‌های مسئله‌محور
- Schema.org برای Organization، WebSite، SoftwareApplication، FAQ و Dataset در صفحات مربوط
- گزارش روزانه/هفتگی با لینک به منبع و روش، بدون ادعای سود
- هشدارهای تعریف‌شده توسط کاربر و اعلان خرابی داده
- سنجش funnel: مشاهده → ثبت‌نام → اولین ارزش → بازگشت → خرید

معیار خروج: رشد ارگانیک همراه با retention و نرخ تبدیل سنجیده شود، نه صرفاً بازدید.

## فاز ۴ — مقیاس ۱۰۰ هزار کاربر

- cache چندلایه، CDN، queue و worker مستقل
- read replica و partition برای تاریخچهٔ قیمت و API usage در صورت نیاز واقعی
- load test بر اساس الگوی ترافیک اندازه‌گیری‌شده
- اپ مشترک iOS/Android و همگام‌سازی اشتراک با سرور
- audit امنیت، بازیابی بحران و status page عمومی

## مواردی که تا دریافت specification متوقف‌اند

- حباب و ارزش نظری طلا، سکه، نقره و ارز
- ضرایب تبدیل و سیاست rounding
- قواعد عیار، مالیات، اجرت و حسابداری مالیاتی
- thresholdهای ایجنت و هر خروجی خرید/فروش
- KYC، تسویه و اجرای معامله در Marketplace
