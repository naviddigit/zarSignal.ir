# بازطراحی گزارش بازار — ۱۰ مهر ۱۴۰۵

## رفتار محصول

روایت شامل وضعیت، دلیل و معنای اختلاف است؛ بخش چهارم، جمع‌بندی، فقط یک بار در کارت نتیجه نمایش داده می‌شود. کارت و استوری از انتخاب مشترک شاخص‌ها استفاده می‌کنند. طلا با دو مبنا، دو بازار مستقل محسوب نمی‌شود. مبنای مستقیم برای گرم ۱۸ و مبنای مظنه برای آب‌شده حفظ شده است. قیمت ربع‌سکه نیز از نرخ خود ربع‌سکه می‌آید.

انتخاب بازار جمع‌وجور است. جزئیات اختیاری پس از نتیجه، بازخورد پیش از لینک‌های فرعی و نمودار نماد در بخش بازشدنی پایین گزارش قرار دارند. متن خصوصی، شناسهٔ حساب و پارامتر درخواست وارد استوری نمی‌شوند. سه چیدمان نبض بازار، تمرکز دارایی و مقایسهٔ طلا/نقره، با تم مستقل روشن/تیره ارائه می‌شوند. نمودار تزئینیِ ساختگی حذف شده است.

نمایش تدریجی از مرز حروف ترکیبی، اعداد و واژه‌های نیم‌فاصله‌دار عبور نمی‌کند. سرعت ۲× دقیقاً دو برابر پایه است؛ سقف و پایه در تنظیمات ادمین محدود و قابل پیش‌نمایش‌اند. تغییر سرعت نمایش را از ابتدا آغاز نمی‌کند. صفحه‌خوان فقط نسخهٔ ثابت متن را می‌خواند. پایان دنبال‌کردن با آماده‌شدن بازخورد هماهنگ است؛ تعامل با فرم یا حرکت عمدی رو به بالا دنبال‌کردن را متوقف می‌کند.

وضعیت ثبت بازخورد از API می‌آید؛ پایان محدودیت باعث استعلام دوباره می‌شود. خطای استعلام، فرم قابل ارسال ایجاد نمی‌کند و دکمهٔ تلاش دوباره دارد. شمارنده «مشاهده‌شده» است، نه تضمین خواندن. تغییر زمان نرخ یا دریافت مجدد به‌تنهایی شناسهٔ تازه نمی‌سازد؛ قیمت، وضعیت اعتبار و تازگی ورودی مؤثر همچنان در هویت گزارش دخیل‌اند.

## مسیر داده و محدودیت‌های واقعی

`Snapshot → computeMarketIndicators → marketViewReportFromSnapshot → روایت / selectReportMetrics → کارت و StoryPublicPayload → PNG`

محاسبات Premium R01.2 دوباره پیاده نشده‌اند. مسیر هشدارهای موجود و قواعد سرور بازخورد تغییر نکرده‌اند. هشدار تأیید معامله فعال نشده است.

منابع بررسی‌شده: `PREMIUM_R01_2_FORMULAS.md`، بستهٔ قرارداد V1 و گزارش ورود آن، `analysis-engine-status.ts`، فرمول‌ها، شاخص‌های مشترک و تست‌های Golden. لینک اشتراک چت V5.7 در ابزار وب، متن قابل‌خواندن برنگرداند؛ محتوای آن مبنای حدس قرار نگرفت.

قواعد اجراییِ همچنان مفقود:

- روند/RSI: الگوریتم، دوره و روش هموارسازی، بازهٔ زمانی معتبر، حداقل کندل، نحوهٔ برخورد با کندل ناقص و آستانهٔ تبدیل به وضعیت روند.
- تصمیم: آستانه‌ها، وزن‌ها، تقدم شروط متعارض، شروط صریح انتظار برای تأیید، confidence و نگاشت Reason Codes؛ نسخهٔ کامل V5.7 موجود نیست.
- سکه: وزن و عیار مصوب، حق ضرب و مبنای دقیق حباب داخلی در برابر فاصلهٔ جهانی؛ قیمت معتبر همچنان نمایش داده می‌شود.
- تبدیل اجرایی: نرخ واقعی دوطرفه، کارمزد و قیود اجرا. خروجی فعلی فقط نسبت نظری است.
- حباب مستقل دلار: متن کامل ZSA-FX-001؛ فاصلهٔ دلار آزاد با دلار ضمنی طلا و مرجع درهم مستقل و با نام روشن باقی مانده‌اند.

تاریخچهٔ روزانه، تحلیل یک‌ساعته تلقی نمی‌شود. نبود داده، محاسبه‌نشدن روند و غیرفعال‌بودن موتور با انتظار واقعی برای شرط متفاوت‌اند. `/api/v1/analysis` تا فراهم‌شدن قواعد مصوب، تصمیم معامله تولید نمی‌کند؛ هیچ HOLD، confidence یا آستانهٔ خریدوفروش از متن نمونه ساخته نشده است.

## بازتولید بررسی‌ها

- `npm test`: تست‌های فرمول، هویت گزارش، انتخاب مبنا، دسترسی، بازخورد و سرعت.
- `npm run typecheck` و `npm run build`.
- ابتدا `npm run dev`؛ سپس `node scripts/verify-analysis-redesign.mjs`.

اسکریپت مرورگر یک مسیر موقت با دادهٔ Golden می‌سازد و در `finally` حذف می‌کند. مسیر تست منتشر نمی‌شود. وضعیت‌های حساب و بازخورد در مرورگر شبیه‌سازی می‌شوند؛ این بررسی، ورود واقعی به حساب Production نیست. اسکریپت چهار عرض ۳۶۰، ۳۹۰، ۷۶۸ و ۱۴۴۰، دو تم، گزارش کل/آب‌شده/دلار/نقره، مهمان، نرخ قدیمی/ناقص، تایپ تا امتیاز، بازخورد و خروجی واقعی PNG را بررسی می‌کند. تصاویر و لاگ‌ها در `tmp/` هستند؛ نمونه‌های آن، دادهٔ آزمایشی‌اند.

QR خروجی نهایی باید از خود PNG رمزگشایی شود و به `https://www.zarsignal.ir/analysis` برسد؛ ابعاد تصویر باید ۱۰۸۰×۱۹۲۰ باشد. محتوای اصلی در محدودهٔ عمودی ۲۵۰ تا ۱۶۵۰ قرار دارد.
