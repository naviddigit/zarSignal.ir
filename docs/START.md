# اجرای زر‌سیگنال

این مخزن نسخهٔ آغازین محصول است؛ انتشار تجاری، پرداخت و مدل تحلیل هنوز آماده نیستند. Readme.md اصلی حفظ شده است.

## وب

Node.js 22.12 یا جدیدتر لازم است؛ برای استقرار از Node 24 LTS استفاده کنید. lockfile را در کنترل نسخه نگه دارید.

```powershell
npm ci
Copy-Item .env.example .env
npm run db:generate
npm run dev
```

نشانی: http://localhost:3000 . حالت demo بدون دیتابیس کار می‌کند. برای build نمایشی متغیر MARKET_MODE=demo در .env بماند. حالت تولید بدون MARKET_MODE هرگز خودکار دادهٔ نمونه نمی‌دهد. robots در پیش‌نمایش noindex است.

## PostgreSQL و پردازشگر

```powershell
docker compose up -d
npm run db:deploy
npm run worker:once
```

اسکریپت worker متغیرها را از `.env` می‌خواند. پیش‌فرض منبع غیرفعال است. برای منبع واقعی، پس از بررسی مجوز دریافت/بازنشر و صفحهٔ واقعی، config/hamrate.example.json را به config/hamrate.json کپی و selectorهای واقعی و verified=true را تنظیم کنید. MARKET_SOURCE_ENABLED=true و MARKET_MODE=live را قرار دهید. اکنون درخواست مستقیم Hamrate در این محیط 403 می‌دهد؛ آداپتور روی صفحهٔ واقعی تأیید نشده و نمونهٔ تنظیمات عمداً اجرایی نیست. هیچ دورزدن محدودیت انجام نشده است. ربات باید تاریخ کامل و منطقهٔ زمانی منبع را بخواند؛ فقط ساعت برای پذیرش داده کافی نیست.

`npm run worker` دریافت دوره‌ای ۵ دقیقه‌ای، timeout، سقف حجم پاسخ، backoff و توقف SIGTERM دارد. یک replica از worker اجرا کنید؛ قفل PostgreSQL و unique constraint مانع نوشتن تکراری هستند ولی اجرای چند worker همچنان می‌تواند درخواست منبع را تکرار کند. دادهٔ ناقص/خراب نوشته نمی‌شود و آخرین دادهٔ سالم باقی می‌ماند. نگه‌داری تاریخچه و پاک‌سازی IngestionRun پیش از تولید باید زمان‌بندی شوند.

## آزمون

```powershell
npm test
npm run typecheck
npm run build
```

آزمون parser از HTML مصنوعی استفاده می‌کند؛ نتیجهٔ آن سازگاری با Hamrate را ثابت نمی‌کند. صحت quota هم‌زمان و تراکنش پرداخت به تست یکپارچه روی PostgreSQL واقعی نیاز دارد.

## موبایل

```powershell
cd apps/mobile
npm ci
Copy-Item .env.example .env
npm run start
```

EXPO_PUBLIC_API_URL برای شبیه‌ساز اندروید `http://10.0.2.2:3000` است. روی دستگاه واقعی، IP محلی کامپیوتر و دسترسی شبکه لازم است؛ برای انتشار HTTPS. برای توسعه، سرور وب را با `npm run dev -- --hostname 0.0.0.0` در شبکهٔ مورد اعتماد اجرا کنید. build آیفون به macOS/Xcode یا سرویس build و حساب امضا نیاز دارد. اپ هنوز روی گوشی یا فروشگاه آزمایش/منتشر نشده است.

## پنل مدیریت

پنل در `/admin` است و فقط با نشست امضاشده باز می‌شود. برای محیط محلی، مقادیر `ADMIN_BOOTSTRAP_TOKEN` و `ADMIN_SESSION_SECRET` در `.env` تنظیم شده‌اند؛ مقدار token را پیش از هر استقرار تغییر دهید و از رمز تصادفی حداقل ۲۴ کاراکتری استفاده کنید. مقدارهای آغازشده با `local-only-` در محیط production پذیرفته نمی‌شوند.

پنل فعلی وضعیت دیتابیس، دریافت داده، اشتراک و API را مشاهده می‌کند. ایجاد کاربر مدیر، نقش‌های چندگانه، تغییر فرمول، فعال‌سازی منبع و فروش پرداختی تا مشخص‌شدن قواعد کسب‌وکار عمداً از پنل قابل تغییر نیستند.
